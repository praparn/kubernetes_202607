Link for download:
1. Check LABSheet on google drive for check information about your machine and your key

2. Install pre-requiste binary as detail below:
  #Cilium Cli
  curl -L --remote-name-all https://github.com/cilium/cilium-cli/releases/latest/download/cilium-linux-amd64.tar.gz{,.sha256sum}
  sha256sum --check cilium-linux-amd64.tar.gz.sha256sum
  sudo tar xzvfC cilium-linux-amd64.tar.gz /usr/local/bin
  rm cilium-linux-amd64.tar.gz{,.sha256sum}

  #Hubble Cli
  export HUBBLE_VERSION=$(curl -s https://raw.githubusercontent.com/cilium/hubble/master/stable.txt)
  curl -L --remote-name-all https://github.com/cilium/hubble/releases/download/$HUBBLE_VERSION/hubble-linux-amd64.tar.gz{,.sha256sum}
  sha256sum --check hubble-linux-amd64.tar.gz.sha256sum
  sudo tar xzvfC hubble-linux-amd64.tar.gz /usr/local/bin
  rm hubble-linux-amd64.tar.gz{,.sha256sum}

3. Test containerd command by running: 
    sudo ctr --version
    sudo ctr image pull docker.io/library/hello-world:latest
    sudo ctr image ls
    sudo ctr container create docker.io/library/hello-world:latest demo
    sudo ctr container list
    sudo ctr container delete demo
    sudo ctr image remove docker.io/library/hello-world:latest
    kubectl version --client=true

4. Clone workshop to aws machine by command: 
    cd ~/
    git clone https://github.com/praparn/kubernetes_202607.git

5. Check module for nftables by command:
    sudo lsmod | grep -e nf_tables -e nf_conntrack
    -----------------------------------------------
    Example output:
nf_tables             286720  0
nf_conntrack          172032  1 nf_tables
nf_defrag_ipv6         24576  1 nf_conntrack
libcrc32c              16384  2 nf_conntrack,nf_tables
    -----------------------------------------------
    *Remark: If module is not appear. Restart machine for activate by command: sudo reboot
    *Remark: kube-proxy's IPVS mode was removed in Kubernetes 1.36 - nftables is now the recommended mode (replacing both IPVS and the legacy iptables mode).

6. Initial kubernetes by command:
    sudo su -
    curl https://raw.githubusercontent.com/praparn/sourcesetup/master/kubernetes_initial/version136/kubeadm-init-basic-containerd.yaml > /tmp/kubeadm-init-basic-containerd.yaml
    kubeadm init --config /tmp/kubeadm-init-basic-containerd.yaml    
    exit

7. Setup credential for regular user by command:
    cd ~/
   	mkdir -p $HOME/.kube
    sudo cp -i /etc/kubernetes/admin.conf $HOME/.kube/config
  	sudo chown $(id -u):$(id -g) $HOME/.kube/config
    kubectl taint nodes --all node-role.kubernetes.io/control-plane-

8. Install cilium network component by command:
    cilium install
    cilium status --wait
    watch kubectl get pods --all-namespaces
    cilium hubble enable --ui
    cilium status --wait
    
9. Check nftables mode on kube-proxy by command:
    kubectl get pods -n kube-system ==> Record kube-proxy name
    kubectl logs kube-proxy-<XXXX> -n kube-system ==> Expect log line confirming "Using nftables Proxier"
    sudo nft list ruleset | head -50 ==> Inspect the kube-proxy nftables rules directly on the node

10. Check Configuration:
    Controller Server: ps -ef | grep kube-controller-manager
    API Server: ps -ef | grep kube-apiserver
    Scheduler: ps -ef | grep kube-scheduler

11. Check Existing Certificate and CSR:
    sudo find /etc/kubernetes/pki/ -type f -name "*.crt" -print|egrep -v 'ca.crt$'|xargs -L 1 -t  -i bash -c 'openssl x509  -noout -text -in {}|grep After'

12. Test deploy application by command:
    kubectl run webtest --image=labdocker/nginx:http2 --port=443
    kubectl get pods -o wide
    kubectl expose pods webtest --target-port=443 --type=NodePort
    kubectl get svc -o wide                                              ==> Record Public Port
    curl ifconfig.me

13. Test access web endpoint by command:
    https://<Public IP>:<Port>
    or
    curl https://<Public IP>:<Port> -v -k

14. Clear up lab by command:
    kubectl delete pods/webtest
    kubectl delete svc/webtest

15. Now all workshop is on "/home/ubuntu/kubernetes_202607"


*Remark: In case you need to reinitial all this lab again please kindly following command below (*Warnning: This will reset all lab that you had been operate before)
    cilium hubble disable
    cilium uninstall --wait
    sudo su -
    kubeadm reset
